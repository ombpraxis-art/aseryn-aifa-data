# ASERYN AIFA Data

Repository remoto del catalogo farmaci per ASERYN.

1. Crea `ombpraxis-art/aseryn-aifa-data`.
2. Copia qui questi file e fai push.
3. Settings → Pages → Source: GitHub Actions.
4. Actions → “Aggiorna archivio AIFA” → Run workflow.

URL atteso dal client:
`https://ombpraxis-art.github.io/aseryn-aifa-data`
